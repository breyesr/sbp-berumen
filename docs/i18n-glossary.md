# i18n Glossary (es-MX / en-US)

Approved terminology for consistent UX copy.

## Security and auth

- `Sign in` -> `Iniciar sesión`
- `Sign out` -> `Cerrar sesión`
- `Access denied` -> `Acceso denegado`
- `Two-factor authentication (2FA)` -> `Autenticación de dos factores (2FA)`
- `2FA code` -> `Código 2FA`
- `Set up 2FA` -> `Configurar 2FA`
- `Verify code` -> `Verificar código`

## Profile and settings

- `Profile & Security` -> `Perfil y Seguridad`
- `Security Settings` -> `Configuración de seguridad`
- `Change Password` -> `Cambiar contraseña`
- `Current password` -> `Contraseña actual`
- `New password` -> `Nueva contraseña`

## Admin and roles

- `User Management` -> `Gestión de usuarios`
- `Create User` -> `Crear usuario`
- `Existing Users` -> `Usuarios existentes`
- `Role` -> `Rol`
- `admin` -> `admin`
- `user` -> `usuario`

## Copy style rules

- Neutral Mexican Spanish (`es-MX`), clear and direct.
- Prefer practical wording over literal translation.
- Keep microcopy short, specific, and action-oriented.
- Avoid region-heavy slang; keep language broad and professional.
